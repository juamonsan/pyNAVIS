## pyNTAVIS: an open-source cross-platform Neuromorphic Tri-axial and Auditory VISualizer

pyNTAVIS is a slightly modified experimental fork of pyNAVIS to add support for tri-axial signals from NTAS (Neuromorphic Tri-Axial Sensor). Refer to the source project <a href="https://github.com/jpdominguez/pyNAVIS">pyNAVIS</a> for more information.
